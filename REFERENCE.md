# GoAlert reference notes

MiniOps uses the uploaded GoAlert repository as a behavioral and architectural reference, not as copied source code.

Reference areas used:
- service integration/routing keys
- alert de-duplication semantics
- incident lifecycle and timeline concepts
- schedules/rotations/temporary overrides
- escalation policy levels
- operational UI patterns
- auditability and test-oriented product behavior

MiniOps remains an independent implementation with its own API, data model, UI, and branding.
